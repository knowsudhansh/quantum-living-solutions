# User Journeys: Quantum Living Solutions

Detailed end-to-end paths for 17 target personas accessing the platform.

---

## 1. Residential Segment

### Homeowner
- **Objective**: Modernize flat/house with intelligent systems.
- **Path**: Lands on homepage -> scroll-story educates on daily routines -> visits /solutions/lighting-automation -> books a showroom demo (chooses pay-on-visit).

### Villa Owner
- **Objective**: Full-scale luxury security, lighting, multi-room audio/video integration.
- **Path**: Lands on homepage -> visits /projects (filters by high-budget villa cases) -> opens booking calendar -> selects slot -> pays booking deposit via Razorpay.

### Apartment Owner
- **Objective**: Non-invasive retrofitted wireless climate and lighting control.
- **Path**: Enters /solutions/residential-automation -> reads about wireless retrofits -> fills contact inquiry form.

---

## 2. Professional & Commercial Segment

### Architect
- **Objective**: Technical specifications, system compatibility, structural aesthetics.
- **Path**: Enters /solutions -> navigates to /projects -> downloads CAD block guides/standards -> registers for consultation demo.

### Interior Designer
- **Objective**: Concealed technology, flush controls, lighting presets.
- **Path**: Enters homepage -> scrolls to cinematic lighting scene -> reviews color templates on /legal/about -> schedule appointment.

### Builder / Developer
- **Objective**: Cost-effective smart solutions for multi-tenant buildings.
- **Path**: Enters via commercial segment -> submits custom inquiry specifying 50+ units.

### Commercial Business Owner
- **Objective**: Smart meeting spaces, integrated boardrooms.
- **Path**: Visits /solutions/commercial-automation -> reviews security and climate controls -> schedules showroom visit.

### Office / Facility Representative
- **Objective**: Scheduling, meeting room occupancy integration, building management system (BMS).
- **Path**: Reviews audio-visual page -> requests a callback for site survey.

### Industrial Customer
- **Objective**: High-durability security, thermal monitoring, perimeter alerts.
- **Path**: Navigates to /solutions/security-and-surveillance -> downloads technical whitepaper -> contacts sales.

---

## 3. Lead & Customer Lifecycle Segments

### Returning Lead
- **Objective**: View updated quote or proceed with demo booking.
- **Path**: Enters via magic link in email -> direct to booking calendar to lock slot.

### Demo Customer
- **Objective**: View demo details, location map, cancel/reschedule.
- **Path**: Opens email link -> accesses self-service portal -> reschedules demo slot (database verifies availability).

---

## 4. Internal Administrative & Staff Segments

### Administrator
- **Objective**: Configure slot pricing, block dates, review security events.
- **Path**: Log in via secure MFA route -> Dashboard -> Settings -> CRM management.

### Sales Team Member
- **Objective**: Review incoming leads, status track, send quotes.
- **Path**: Opens dashboard -> selects "Qualified Leads" -> updates lead state -> logs follow-up call detail.

### Demo Operator
- **Objective**: Prepare showroom for upcoming booked user preferences.
- **Path**: Reads upcoming booking itinerary -> configures preset physical modes in showroom.

### Finance / Payment Reviewer
- **Objective**: Reconcile Razorpay transactions with internal database entries.
- **Path**: Dashboard -> Payments -> triggers reconciliation command -> reviews unresolved deposits.

### Support Team Member
- **Objective**: Respond to customer inquiries or complaints.
- **Path**: Reads dashboard inquiry feeds -> opens contact ticket -> logs response.

### Job Applicant
- **Objective**: Apply for open career positions.
- **Path**: /careers -> reviews job description -> uploads resume -> checks application progress.
